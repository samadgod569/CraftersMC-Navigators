Live Console
Stream real-time output from your container. Watch logs as they happen and catch errors instantly without SSH or extra tooling.
Automated Backups
Your app data is backed up automatically. Restore to a previous state in one click when something breaks or goes wrong.
GitHub Deployment
Connect any GitHub repository. Cloudra pulls your code, installs dependencies, and starts your app automatically.
Environment Variables
Set secrets and config values per app. Variables are injected into your container at runtime and never exposed in logs.
Isolated Containers
Every app runs in its own Docker container with dedicated resource limits. Fully sandboxed with no noisy neighbors.

.github/workflows/deploy.yml GitHub Actions
name: Deploy to Cloudra

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Deploy
        run: |
          curl -X POST https://cloudra.vortexa.cloud/api/deploy \
            -H "Content-Type: application/json" \
            -d '{
              "username": "c69p2w",
              "password": "${{ secrets.USERPASS }}",
              "appName": "app1",
              "appPassword": "${{ secrets.APPPASS }}",
              "repo": "${{ secrets.REPO }}",
              "language": "nodejs",
              "startFile": "index.js",
              "packages": ["express"]
            }'
CI/CD

Push to main.
You are done.

Wire Cloudra to your GitHub Actions workflow with a single curl call. Every push to main triggers a fresh deploy automatically.

Automatic dependency install
Cloudra reads your package.json or requirements.txt and installs everything before starting your app.
Zero-downtime redeploy
The old container keeps serving while the new build completes. The swap is instant when the container is ready.
Secret management
Store credentials as GitHub secrets and pass them at deploy time. They never touch your repository code.
