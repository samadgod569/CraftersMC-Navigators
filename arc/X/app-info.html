How To Set Up
1
Add an A Record
Go to your DNS provider (Cloudflare, Namecheap, etc.) and add an A record pointing your domain to 45.137.70.54. Leave proxy disabled (grey cloud in Cloudflare).
2
Wait for DNS Propagation
DNS changes can take a few minutes to an hour. You can verify by running nslookup yourdomain.com — it should return 45.137.70.54.
3
Enter Your Domain Below
Once DNS is pointing to the server, enter your domain and hit Assign. We'll verify the DNS record automatically before activating it.
